## 完成项

### L1. 设计 token 化完成（清零 arbitrary color 类）

**27 处** Tailwind arbitrary-value color 类映射到设计 token，全项目 arbitrary color 清零。

映射依据 `tokens.css` 的 dark-mode 规范（`--bg-page: #0a0a0a` / `--bg-surface: #171717`）与 `tailwind.config.ts` 的 gray 色阶：

| arbitrary 值 | 出现次数 | token 映射 | 依据 |
|---|---|---|---|
| `bg-[#0a0a0a]` | 3 | `bg-gray-950` | gray-950 = `#0A0A0A`（精确匹配，page bg）|
| `bg-[#171717]` | 12 | `bg-gray-900` | 最近命名色阶（surface bg，#111827 ≈ #171717）|
| `bg-[#111]` | 11 | `bg-gray-950` | dark page bg 规范（#111 ≈ #0a0a0a）|
| `text-[#DC2626]` | 1 | `text-error` | error DEFAULT = `#DC2626`（精确匹配）|

涉及 14 个源文件 + 2 个测试文件。测试断言（`ChartToolbar.test.tsx` / `TimeframeSelector.test.tsx`）同步从 `bg-[#171717]` → `bg-gray-900`，保持一致。

**验证：** `grep` 确认 0 处残留 arbitrary color 类；`pnpm build` 成功（token 全部在 tailwind config 中解析）。

### L9. a11y 修复

扫描全部 input / img / 交互元素：

- **修复 1 处：** `app/apikeys/page.tsx` 的 created-API-key 展示框 — 原用 `<span>Your API Key:</span>`（非 label）且 input 无 `id`/`aria-label`。改为 `<label htmlFor="created-api-key">` + `id="created-api-key"`，建立正确的程序化关联。
- **其余 5 处 input 全部合规：** `Input.tsx` 组件用 `useId()` 自动生成 id + `htmlFor` 关联；2 个 color input 有显式 `<label htmlFor="ts-color">`；2 个 checkbox 用包裹式 `<label>`（"Remember me" / 指标开关）。
- **全部 `<img>` 有 alt：** 多行扫描确认 3 张 about 页头像均有语义 alt（Marcus Chen / Elena Vasquez / David Okonkwo）。

### L10. CSP 收紧（生产移除 unsafe-eval）

**生产 CSP `script-src` 移除 `'unsafe-eval'`**（dev 保留，Next.js Fast Refresh 需要）：

```
production: script-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net
dev:        script-src 'self' 'unsafe-inline' 'unsafe-eval' https://cdn.jsdelivr.net
```

依据：扫描确认应用代码无 `eval()` / `new Function()` 直接调用；Next.js 生产 build 不需要 eval。

**`'unsafe-inline'` 暂保留** — 移除需要 nonce-based CSP 基础设施（Next.js 注入 inline runtime chunks），是更大的工程，记为后续 follow-up。

**验证：** 生产 `/login` 响应头确认 `script-src` 不含 `'unsafe-eval'`，页面 200 正常加载。
