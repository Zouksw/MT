### A. ✅ 删 `types/index.ts:67` 重复 AuthenticatedRequest

**根因：** 项目有 **3 个** AuthenticatedRequest 定义：
- `middleware/auth.ts:5` `AuthRequest`（userId optional，旧）
- `middleware/auth.ts:16` `AuthenticatedRequest`（userId required，**canonical**）
- `types/index.ts:67` `AuthenticatedRequest`（第三份，shape 又不同：无 userId，user 带 email+role）

**取证：** 所有实际用法都 `import { type AuthenticatedRequest } from "@/middleware/auth"`（analytics.ts/watchlist.ts 等）。`types/index.ts` 的版本 **0 importers**——`timeseries.ts` 虽 `import { QueryConditions } from "@/types"`，但不导入该类型。

**修复：** 删 `types/index.ts:67` 的 interface，留注释指向 canonical 版本。

### B. ✅ 删死 MSW 测试基础设施（handlers.ts 188 行 + server.ts + msw devDep）
