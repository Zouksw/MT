## 发现的潜伏 bug (重构副产物) ✅

HTTP 烟测发现 `/api/watchlists/:id/quotes` 500: `operator does not exist: text = uuid`。

**根因**: 原 quotes 路由的 raw SQL 用 `::uuid[]` 类型转换,但 `commodity_prices.commodity_id`
是 **text 列** (经 `information_schema` 实查确认)。list 路由用 `::text[]` (正确),quotes 路由用
`::uuid[]` (错误) — **原路由就有这个 bug**,只是之前可能没人调过 quotes 端点。

**修复**: `batchRecentPricePairs` 改 `::uuid[]` → `::text[]`。

**双向回归测试**: 新增 "runs the price-pair batch query without a type-cast error" 测试。
把 `::text[]` 改回 `::uuid[]` → 测试 **FAIL** (Prisma 抛 text=uuid); 恢复 → **PASS**。
