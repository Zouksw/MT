## 结论（批1 两问的答案）

1. **chronos 在牛肉月度上"劣于 naive"的淘汰结论不成立于 H=1**：FX/CME 日更池的淘汰证据（chronos 中位 0.79-0.82 vs naive 0.41）在牛肉月度 H=1 上不复现——chronos_tiny 1.61% / base 1.71% vs naive 1.69%，与 naive 同一带内。**但 H=3 成立**：chronos 三变体 3.28-3.91% 全部明显劣于 naive 2.71%（劣化 21-44%），arima 2.64% 最优。→ 现行全局淘汰对牛肉 H=1 过严、对 H=3 合理，**per-series/per-horizon 路由（批 2）有了直接证据**。
2. **月度宏观序列的可预测上限就在 naive 附近**：7 模型中位挤在 1.46-2.08%（H=1）/ 2.64-3.91%（H=3），最优 arima 仅比 naive 好 14%（H=1）/ 3%（H=3）。与 M6 竞赛教训（163 队仅 1 队跑赢 naive）形态一致——品牌叙事应以"可验证 + 方向 + 区间"为主，而非"更准的大模型"。
3. **arima 是牛肉月度冷启动冠军**（两 horizon 中位 MAPE 均最优；方向命中 61%；区间覆盖率 91.7%/94.1% 贴 90% 名义值）。批 2 的牛肉序列初始权重应以本表为准。
4. **chronos 原生区间在牛肉月度上系统性欠覆盖**（58-78% vs 名义 90%；统计模型 90-94% 校准良好）——生产侧 conformal 校准层（intervalCalibration）对 chronos 是必要的，此表即校准前基线；relational conformal 升级（PRED-STRATEGY §7.3 登记）有了本仓自己的动机数据。
5. **方向命中是唯一有"边际"的指标**：H=1 上 chronos_base 69.4% / mini 63.9% / arima 61.1%（掷硬币 50%）；H=3 全员回落至 38-59%（≈无信息）。批 4（方向准确率进验证环与展示）的价值判断被证实：月度尺度上有信号、季度尺度上诚实地说没有。
6. **复现**：chronos 每请求 payload 派生种子 + 本脚本串行调用——3-origin 对照两次运行 md5 一致（d8a01b59…）；全表重跑 `cd backend && npx tsx scripts/backtest-monthly-series.ts` 逐位一致。
